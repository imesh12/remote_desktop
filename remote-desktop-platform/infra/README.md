# Infrastructure Scaffold

This directory contains placeholder infrastructure scaffolding for local development and future deployment work.

## Included Services

- `server`: placeholder container for the NestJS control plane
- `postgres`: future primary relational database
- `redis`: future cache, pub/sub, and ephemeral coordination store

## Current Status

The Compose file is intentionally non-production and non-functional beyond service structure. It exists to reserve the environment shape for later implementation work.
